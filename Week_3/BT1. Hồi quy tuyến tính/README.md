**Hồi quy tuyến tính (Linear Regression):** Tính toán hệ số cho các mô hình hồi quy đơn biến, đa biến và hồi quy đa thức[cite: 1].
**Hồi quy phân lớp (Classification):** Phân loại dữ liệu bằng đường quyết định tuyến tính, Logistic Regression và Perceptron Learning[cite: 1].
**Tối ưu hóa và Đánh giá:** Thực hiện cập nhật trọng số bằng thuật toán Gradient Descent, tính toán các hàm mất mát (MSE, Cross-Entropy) và áp dụng các phương pháp chuẩn hóa như Ridge Regression, LASSO Regression
