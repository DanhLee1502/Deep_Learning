**Hồi quy Logistic:** Xây dựng mô hình phân loại nhị phân (dự đoán giới tính trẻ sơ sinh, chất lượng phim). Tối ưu hóa trọng số bằng thuật toán Batch Gradient Descent với hàm mất mát Binary Cross-Entropy.

**Đồ thị tính toán và Lan truyền ngược:** Phân rã các biểu thức toán học, thực hiện Forward Pass và Backward Pass thủ công để tính toán gradient dựa trên quy tắc dây chuyền.

**Triển khai bằng Python:** Lập trình huấn luyện mô hình, trực quan hóa ranh giới quyết định (Decision Boundary) và kiểm chứng độ chính xác của các bước tính toán thủ công bằng thư viện NumPy và PyTorch (Autograd).
